# C 车 yaw PID 固定基线测试

当前 C 车配置开启 `yaw_pid_test_enabled: true`。使用原角度/速度 PID，参数未改；自瞄、手动目标输入在测试模式中被屏蔽，底盘、悬挂、摩擦轮和拨弹保持失能。pitch 在测试时保持触发方向。测试挡位以外 yaw/pitch 均停止驱动。失能不等于主动刹停。

## 编译、同步与触发

编译 `rmcs_core` 和 `rmcs_bringup`，按车端架构选择现有构建/交叉构建流程；两者必须一起同步，只有配置没有新控制器代码无法运行。同步前保存本轮完整配置，后续不要用已修改的新参数覆盖它：

```bash
mkdir -p yaw-pid-baseline
cp rmcs_ws/src/rmcs_bringup/config/deformable-infantry-omni-c.yaml yaw-pid-baseline/config.yaml
```

由操作者确认云台 ±25° 范围及线缆余量后，双下启动 C 车配置。双中准备，左保持中、右拨上开始测试。右上仅作为测试触发，不进入自瞄。全程保持左中右上。

离开左中右上立即停止驱动；正常完成仍保持中心，不会重复。再次双中再右上可重新执行。故障锁停必须双下复位。遥控失联停止驱动，恢复后需要重新双中准备。

## 固定动作（总计 56 秒）

| 时间 | 阶段 | 目标 |
|---|---|---|
| 0–3 s | 0 静止 | 触发时方向 |
| 3–27 s | 1 阶跃 | +5°、0°、−5°、0°，每段 2 秒，重复 3 轮 |
| 27–43 s | 2 匀速与停止 | 0→+10→0→−10→0，每段移动 1 秒，停 1 秒，重复 2 轮 |
| 43–53 s | 3 正弦 | ±5°，固定 0.5 Hz，5 周期 |
| 53–56 s | 4 收尾 | 保持中心 |

目标为触发方向附近的相对偏移，通过原云台方向解算器注入；不将电机相对底盘角度作为世界角度。测试需要底盘固定，避免人为移动底盘；不向测试动作叠加自瞄前馈。本轮测试比较的是角度环与速度环共同表现，不能单独证明速度环最优。

保护：测试总输出力矩限幅 ±3 N·m；编码器或 IMU yaw 速度达到 90°/s、相对起始编码器角度偏移达到 25°、反馈非有限、控制输出非有限、执行周期无效或超过 50 ms 均锁停。±3 N·m 是本次测试限幅，并非硬件安全额定值；以后比较时保持一致。测试运行使用执行器单调时钟，日志 200 Hz。完成后仍保持输出，双下退出。

## 日志与比较

日志 `/tmp/yaw_pid_monitor_<timestamp>.csv`。列包括测试时间、阶段、相对目标、active/fault/done、角度误差、速度目标、IMU/编码器速度和指令/反馈力矩；index 为采样编号，测试 time 为执行器时钟。目标 offset 与误差均为 rad，速度 rad/s，力矩 N·m。故障后 stage=-1，fault=1；正常完成 done=1（active 仍为 1 表示中心保持）。完成后留约 1 秒再双下，停止服务后下载日志。

本地分析：

```bash
python3 .script/identification/analyze_yaw_pid_test.py 本次日志.csv \
  --config yaw-pid-baseline/config.yaml --output yaw-pid-baseline/report
```

输出逐次运行、逐阶段 RMSE/峰值/平均误差、速度波动、力矩峰值/RMS/限幅占比、逐阶跃进入 ±0.2° 后保持至该段结束的稳定时间，以及末 0.5 秒平均误差。缺失完整动作、故障或时间缺口过大的运行不作为有效基线。无有效运行时脚本以非零状态退出；原始日志也应保留。配置快照必须与采集时车端一致；分析器当前按本模板 ±3 N·m 统计饱和占比。

每轮保持动作、限幅、前馈与机械状态一致，只改一个 PID 参数；完整运行至少一次，结果接近时重复确认。首轮只建立参照，不自动修改参数。

退出专用测试、恢复日常遥控时，将 `yaw_pid_test_enabled` 改为 `false`；底盘和发射机构需按实际使用场景另行恢复。
