# yaw PID 首轮实测基线

原始日志：`yaw_pid_monitor_2026-10-16_08-05-40.csv`。文件名保留车端时间，不作为已校准的本地时区时间。

结论：识别出 1 次完整 56 秒测试，done=1，整个文件 fault=0；活动区间控制数据均有限，测试时间最大相邻间隔约 7 ms。可作为后续同模板比较的实测基线。

配置来源：下载目录最初只有 CSV，`config.yaml` 是分析时从当前本地 C 车配置复制的；未独立核对当时车端参数。按本地配置，角度环 Kp/Ki/Kd=10/0/0，速度环=13/0.02/0，测试指令力矩限幅 ±3 N·m。比较前应确认这些与采集时一致。

| 阶段 | 角度误差 RMSE | 最大绝对误差 | 指令力矩限幅占比 |
|---|---:|---:|---:|
| 初始静止 | 0.012° | 0.023° | 0 |
| 角度阶跃 | 0.818° | 4.276° | 4.92% |
| 匀速往返 | 0.696° | 1.139° | 0 |
| 0.5 Hz 正弦 | 1.090° | 1.550° | 0 |

12 次阶跃均在各自 2 秒窗口内进入并保持在 ±0.2°，稳定时间 0.345～0.460 s，平均 0.383 s。各阶跃末 0.5 秒平均误差绝对值约不超过 0.031°。稳定时间依据实际记录的目标切换分段，采样和时间舍入使切换时刻有约一个采样周期的不确定性。

静止保持误差很小；持续运动的误差更值得优先改善。阶跃已经短时达到力矩限幅，提高增益不一定同比缩短响应时间。当前结果不能仅凭外环测试确定最优速度环参数；本次不改 PID，保留这份基线供下一轮对照。

反馈力矩约 -3.643～+3.248 N·m，超出的是反馈值；±3 N·m 限幅作用于控制指令，不保证反馈严格在同一范围。

结果文件：

- `report/summary.json`：各阶段及逐阶跃指标。
- `report/baseline.svg`：目标、角度误差、速度目标/反馈、力矩指令/反馈曲线。
- `config.yaml` 和 `report/config.yaml`：分析时保存的本地配置候选快照。

最后保持阶段统计包含完成后的额外中心保持；下次若比较该阶段应固定窗口。初始保持、阶跃、匀速和正弦阶段为固定窗口。
