# yaw PID Kp=11 对照结果

日志 `yaw_pid_monitor_2026-10-16_08-25-54.csv` 含一轮完整 56 秒流程，未触发保护；活动段最大相邻时间间隔 9 ms。最后一行 CSV 写入不完整，分析时明确跳过，仅影响完成后的保持段；原始文件未改。

配置快照与基线候选配置相比仅 yaw_velocity_kp 从 13 改为 11。基线配置是在采集后从本地补存，尚未独立核对当时车端参数。

| 指标 | Kp=13 | Kp=11 |
|---|---:|---:|
| 静止角度误差 RMSE | 0.0122° | 0.0195° |
| 阶跃角度误差 RMSE | 0.8182° | 0.8143° |
| 平均阶跃稳定时间，±0.2° | 0.3829 s | 0.3792 s |
| 阶跃力矩指令 RMS | 0.8590 N·m | 0.8025 N·m |
| 阶跃指令力矩限幅占比 | 4.92% | 4.38% |
| 匀速角度误差 RMSE | 0.6959° | 0.6975° |
| 正弦角度误差 RMSE | 1.0900° | 1.0959° |
| 12 次阶跃平均反向回摆速度 | 3.90°/s | 3.92°/s |
| 最严重一次反向回摆速度 | 5.31°/s | 6.16°/s |

回摆定义：按每次实际记录的目标跳变对齐，正负方向统一；IMU 速度先插值至 200 Hz，并取 25 ms 移动平均，再统计阶跃后 100～300 ms 内反向速度峰值。它描述低频瞬态回摆，不能替代对高频机械振动的测量。两轮各只有一次，微小变化不能视为可靠改善或恶化。

结论：降低 Kp 减少了阶跃输出力矩 RMS 和限幅比例，但没有明显改善速度回摆。稳定时间和连续运动误差基本持平。因此不能宣布震动问题解决，也没有证据支持持续盲目降低 Kp。本轮未进一步修改参数。

`report/comparison.svg` 显示方向统一后的 12 次阶跃平均速度、力矩指令及角度误差；平均曲线可能掩盖单次最坏情形，应结合 `report/rebound_comparison.json` 的逐阶跃值。`report/summary.json` 是完整阶段指标。`report/compare.py` 可在仓库根目录重建比较图和回摆指标。
